# 戦闘状態とマナ自然回復

関連Issue: https://github.com/RuskServer/Deepwither_V2/issues/52

## 回復量

`ManaManager` が20tickごとに最大マナの2%を回復し、戦闘外では3%を追加して合計5%を回復します。
安全地帯でも戦闘状態を優先します。死亡・スペクテイター（ダウン中を含む）には自然回復を適用しません。
調整値は `ManaRegeneration`、解除時間は `CombatStateTracker.EXIT_DELAY_MILLIS` に定義しています。
HP回復量・スキル消費・ポーション回復量はこの変更の対象外です。

## 戦闘判定

- 成立した通常攻撃・スキル攻撃・パイプライン経由の継続ダメージで双方を戦闘扱いにします。バリアで吸収された命中も含みます。
- 禁止PvP・同パーティへの攻撃・空振り・環境ダメージ・単なるマナ消費では開始しません。
- 最後の攻撃・被攻撃・戦闘中の味方への支援・モブの追跡確認から8秒で解除します。
- バニラAIのターゲットを追跡し、カスタムAIは対象選択時に `CustomMob#combatTarget` で通知します。
- ボス参加中は時間経過だけでは解除しません。ダンジョンではボス出現後の参加者を同期します。
- ボス撃破・消滅・ダンジョン終了で参加状態を解除します。別ワールドへの移動では旧ボスの参加状態のみ解除し、直近の8秒制限は保持します。
- ダウン中はボス参加状態を保持し、実際の死亡・ログアウトではプレイヤーの一時状態を破棄します。

## 支援を実装する場合

実際の効果適用箇所で、支援者と対象を渡してください。

```java
healthManager.heal(caster, ally, amount);
healthManager.setBarrier(caster, ally, amount);
// バフなどの付与が成立した後
combatState.recordSupport(caster, ally);
```

回復はHPが増えた場合に通知します。継続回復は各回の回復時に通知します。
戦闘外の味方への支援と自己回復では戦闘時間を延長しません。
ボス参加中の味方を支援した場合は支援者もそのボスの参加者になります。
自然回復や使用者本人へのアイテム効果には、既存の発生元なしAPIを使えます。

## 表示

スキルモードの既存アクションバーに戦闘状態を表示します。詠唱中は既存の詠唱表示を優先します。
通常時のHUDでは、PlaceholderAPIの `%deepwither_combat_status%`、`%deepwither_in_combat%`、`%deepwither_mana_regen%` を利用できます。
`mana_regen` は状態に応じた毎秒の回復量です。

## 確認

`gradlew.bat build` で8秒の境界、追加行動による延長、支援、複数ボス、退出・終了、回復量と上限をテストします。
実機では次を確認してください。

- ソロ戦闘終了後に回復が5%へ切り替わり、再攻撃で2%へ戻る。
- 追跡中・ボスの長い予備動作中・ヒーラー支援中に戦闘外回復へ移行しない。
- 禁止PvP・移動スキル・戦闘前バフ・落下で不要な戦闘状態にならない。
- ダウン・蘇生・退出・ボス消滅後に参加状態が残留しない。
- DI起動・停止が正常で、スキル表示や既存HUDと干渉しない。
