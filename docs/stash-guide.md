# 拡張スタッシュシステム

物理エンダーチェストを右クリックすると、バニラのエンダーチェストの代わりに
永続スタッシュを開きます。

## 容量とアップグレード

* 初期容量は1ページ（27枠）です。
* 1回のアップグレードにつき1ページ（27枠）増加します。
* 最大容量は6ページ（162枠）です。
* アップグレードは確認画面を経由し、Vault残高から費用を支払います。

価格は `StashService` の `UPGRADE_PRICES` で管理します。

## キャラクターモードごとの所有単位

* `STANDARD` / `SOFT_HARDCORE`: プレイヤー単位の共有スタッシュ
* `TRUE_HARDCORE`: キャラクター単位の専用スタッシュ

共有スタッシュは `SharedStashDataProvider`、キャラクター専用スタッシュは
`CharacterStashDataProvider` を通じて保存します。真HCから共有スタッシュへ
アイテムを移動することはできません。

## 保存形式

`StashData` は以下を保持します。

* 解放済みページ数
* バニラエンダーチェスト移行済みフラグ
* 全体スロット番号とBase64化したItemStackの対応表

ItemStackの変換には Paper の `serializeAsBytes()` / `deserializeBytes()` を使用します。
GUI操作後、ページ切り替え時、GUI終了時、プレイヤー退出時、プラグイン停止時に保存します。

## バニラエンダーチェストからの移行

共有スタッシュの初回オープン時に限り、プレイヤーのバニラエンダーチェスト内容を
第1ページへ移します。スタッシュ側の保存に成功した後で、バニラ側を空にします。

真HCスタッシュでは、プレイヤー共有のバニラエンダーチェスト内容を取り込みません。
これにより、バニラ領域を経由した真HCへのアイテム持ち込みを防止します。

## GUI実装上の注意

スタッシュはアイテムの出し入れを許可するため、全クリックをキャンセルする共通
`GuiService` ではなく、専用の `StashInventoryHolder` と `StashListener` を使用します。
操作行、確認画面、クリエイティブの複製操作はキャンセルし、セッショントークンで
古いページのイベントが現在のページへ干渉しないようにします。
